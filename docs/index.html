01 — La idea

Un enlace que no caduca.

La permaweb promete almacenamiento permanente. La aplicación convierte esa promesa en un flujo de producto: cotizar, subir, compartir y administrar.

El problema

Los enlaces convencionales mueren cuando el proveedor cierra, cambia de precio o borra el archivo. Para documentos, portfolios y evidencia, esa fragilidad es inaceptable.

La solución

Una app Next.js que cotiza el costo de almacenamiento permanente, sube el archivo a la permaweb, guarda metadatos en PostgreSQL y expone una URL estable con QR y descarga por slug.

02 — El recorrido

Cómo funciona, paso a paso

Del archivo local a un enlace permanente, con costo y estado visibles.

01

Cotizar

El usuario elige un archivo y recibe el costo estimado de publicarlo para siempre.

02

Subir

La API sube el contenido a la capa de almacenamiento permanente y confirma el recibo.

03

Compartir

El sistema genera un slug, una URL estable y un QR para abrir o descargar.

04

Administrar

El panel lista archivos, usuarios y estados; el historial muestra cada publicación.

03 — Bajo el capó

Permanencia con metadatos vivos

El contenido vive en la permaweb; la aplicación mantiene usuarios, cotizaciones y permisos en PostgreSQL.

Contenido inmutable

El archivo se publica una vez y se referencia por su identificador permanente.

Metadatos operativos

Slug, dueño, estado y permisos viven en una base relacional.

Descarga directa

La URL pública no depende de una sesión ni de un servidor de archivos propio.

04 — Lo que lo hace distinto

Decisiones de ingeniería

Diseñado para que la permanencia sea una decisión de producto, no un efecto colateral.

Cotización

Precio estimado antes de publicar, con moneda y tamaño visibles.

Subida

Slug estable
